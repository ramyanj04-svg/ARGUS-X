Pipeline

one perception cycle per frame
  1. 01Camera compensation

    ORB + RANSAC translation estimate shifts every prediction into the current frame.

  2. 02Motion prediction

    Per-track Kalman filter on centre, aspect and height with damped velocity while lost.

  3. 03Appearance embedding

    Standardised colour layout + HSV histogram + gradient texture, quality-gated.

  4. 04Association

    Two-stage gated Hungarian matching; low-confidence detections need motion and appearance.

  5. 05Identity memory

    EMA embedding plus a 12-crop gallery; identities outlive tracks for 900 frames.

  6. 06Verified recovery

    Class, time, motion, multi-cue appearance and ambiguity gates, then a 3-frame confirmation.
